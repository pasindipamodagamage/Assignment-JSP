# 📘 JSP Assignment Repository

Welcome to the JSP Assignment Repository! This project showcases various assignments and exercises related to JavaServer Pages (JSP) technology.

## 📂 Project Structure

- **src/**: Contains the Java source code files.
- **web/**: Holds the JSP files and web resources.
- **lib/**: Includes necessary libraries and dependencies.
- **README.md**: This file, providing an overview of the project.

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/pasindipamodagamage/Assignment-JSP.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd Assignment-JSP
   ```
3. **Set up your development environment**:
   - Ensure you have the latest version of Java Development Kit (JDK) installed.
   - Use an Integrated Development Environment (IDE) like IntelliJ IDEA or Eclipse for optimal experience.
4. **Deploy the application**:
   - Configure your IDE to deploy the project on a web server like Apache Tomcat.
   - Start the server and access the application through your browser.

## 🛠️ Features

- **Dynamic Content Rendering**: Utilizes JSP to generate dynamic web pages.
- **Form Handling**: Demonstrates handling user input through forms.
- **Session Management**: Implements session tracking to maintain user state.
- **Database Connectivity**: Connects to a database to perform CRUD operations.
